Radix-4 Booth Multiplier

Project Overview

The Radix-4 Booth Multiplier is a digital arithmetic circuit used to perform signed binary multiplication efficiently. It uses Radix-4 Booth encoding to reduce the number of partial products by processing two multiplier bits at a time.

Key Features

- Signed binary multiplication using 2's complement.
- Radix-4 Booth encoding.
- Reduced number of partial products.
- Improved multiplication efficiency.

Working Principle

The multiplier examines overlapping groups of three bits and selects one of the following operations: 0, +M, -M, +2M, or -2M, where M is the multiplicand. The generated partial products are shifted and added to obtain the final result.

Example

Multiplication: 5 × 3 = 15

Technologies

Digital Electronics, Computer Architecture, Binary Arithmetic.
